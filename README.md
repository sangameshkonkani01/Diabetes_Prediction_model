# Health Risk Prediction – Diabetes Risk Checker

A simple machine learning project that estimates the risk of diabetes from user-provided health parameters.

> **Note:** This project is for educational/demo purposes only and is not a medical diagnostic tool.

---

## 🌟 What this project includes

- A **trained RandomForest model** that predicts the probability of diabetes.
- A **Streamlit web app** to enter health parameters and display a risk estimation.
- A **command-line test script** for quick predictions.
- A training script to generate model artifacts (`models/diabetes_model.pkl` + `models/diabetes_scaler.pkl`).

---

## 🧰 Technologies Used

- Python 3.11+
- Streamlit
- scikit-learn
- pandas / numpy

## 🚀 Quick Start (Local)

### 1) Install dependencies

```bash
pip install -r requirements.txt
```

### 2) Train the model (creates `models/` artifacts)

```bash
python save_diabetes_model.py
```

This will create:
- `models/diabetes_model.pkl` (the trained classifier)
- `models/diabetes_scaler.pkl` (the scaler used to normalize features)

### 3) Run the Streamlit app

```bash
streamlit run app/app.py
```

Open the URL shown in the terminal (default: `http://localhost:8501`).

---

## 🧪 Test Predictions via CLI

```bash
python test_diabetes_model.py
```

Then enter the requested health parameters to get a predicted risk and probability.

## 🧠 Model & Prediction Details

### Input features (in order)

1. Pregnancies
2. Glucose
3. BloodPressure
4. SkinThickness
5. Insulin
6. BMI
7. DiabetesPedigreeFunction
8. Age

### Model pipeline

1. Load data from `data/diabetes.csv`
2. Split into training and test sets
3. Scale features with `StandardScaler`
4. Train a `RandomForestClassifier`
5. Save the model and scaler using pickle

### Risk categorization

- **Low Risk**: probability < 0.40
- **Medium Risk**: 0.40 ≤ probability < 0.70
- **High Risk**: probability ≥ 0.70

## 🔧 Troubleshooting

### Missing model files

If the app reports missing `diabetes_model.pkl` or `diabetes_scaler.pkl`, run:

```bash
python save_diabetes_model.py
```

### Streamlit errors

If Streamlit fails to start, ensure you're using Python 3.11+ and that dependencies are installed:

```bash
python -m venv .venv
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
